RF Monitor Dashboard

ECE Project

Overview

A low-cost indoor RF propagation experiment built around an ESP32. The board measures Wi-Fi RSSI (dBm) every second, streams it over USB serial to a local Flask dashboard, and stores samples with a manually entered distance label. Collected data is exported as CSV and analysed with a MATLAB script that fits the log-distance path-loss model.

Distance is always a manual label — it is never calculated from RSSI.

Objectives

  • Measure indoor Wi-Fi RSSI as a function of distance using an ESP32.
  • Build a real-time local dashboard for live monitoring, storage, and export.
  • Fit the log-distance path-loss model RSSI(d) = A + B·log10(d) and report path-loss exponent n = -B/10.
  • Keep all hardware low-cost and the workflow simple and reproducible for a student lab.

ESP32 Data Flow

On boot the firmware connects to Wi-Fi and prints the header line TIME_MS,RSSI_DBM once. Thereafter, while connected, it prints one CSV line per second: millis(),WiFi.RSSI(). While disconnected, it prints only lines starting with # (comment/debug) and never prints fake RSSI. The Flask reader thread parses "time_ms,rssi_dbm" lines, ignores headers/comments/blanks/malformed lines, and appends to a thread-safe store where Time_ms is elapsed ms since collection start and Distance_m is the label active at arrival.

See the source: firmware/esp32_rssi/esp32_rssi.ino

Experimental Procedure

  1. Place the ESP32 at the target distance from the router (e.g. 1, 2, 3, 5, 10 m).
  2. Enter the distance label in the dashboard and click Set Distance.
  3. Click Connect; let it collect for 30–60 seconds (enough samples per group).
  4. Click Export CSV; save the file (e.g. rssi_data.csv).
  5. Click Clear; repeat for the next distance.
  6. After all distances: open MATLAB, run RF_Monitor_Analysis.m, select the CSV, view figures A–E and the grouped-statistics export.

MATLAB Analysis

The script matlab/RF_Monitor_Analysis.m validates the CSV columns, drops non-numeric / non-positive-distance rows, and produces:

  • Figure A: RSSI vs time.
  • Figure B: RSSI vs distance (individual readings).
  • Figure C: per-distance statistics table (mean, std, N) in MATLAB.
  • Figure D: mean RSSI vs distance with std error bars.
  • Figure E: fitted log-distance model over measured means.
  • Fit: RSSI(d) = A + B·log10(d), with slope B, intercept A, path-loss exponent n = -B/10, and R². Uses mean RSSI per distance (groups with N ≥ 2).
  • Grouped-statistics CSV exported next to the input file.

Figures are saved as PNG so they can be uploaded to the dashboard's MATLAB Output Graphs gallery.
