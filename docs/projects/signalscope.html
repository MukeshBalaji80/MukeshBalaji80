SignalScope — RF Signal Monitoring.

An ESP32-based project in progress to capture Wi-Fi signal-strength (RSSI) readings, stream live serial data and visualize signal variation in MATLAB.

IN PROGRESSWork in progress · not a completed system
CATEGORYEmbedded systems / RF
PLATFORMESP32
TOOLSSerial data · MATLAB

Project overview

The project is intended to read Wi-Fi RSSI values using an ESP32, stream readings over serial and explore their visualization in MATLAB.

The broader learning focus is to understand how signal strength varies indoors and connect practical measurements with radio-wave propagation concepts.

Current scope

  • ESP32-based Wi-Fi signal-strength capture
  • Live serial data collection
  • MATLAB visualization of signal variation
  • Exploration of indoor radio-wave propagation

Detailed hardware configuration, measurement results, plots and validation evidence will be added when they are available.
